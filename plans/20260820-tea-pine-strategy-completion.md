# Tea Pine-strategy completion

- Status
  - Planned from a current-code audit on 2026-08-20 at `f456f50`.
  - Supersedes only the stale WGSL-eligibility claims in older strategy plans.
  - Preserves the adopted direct `trade.nextOpen` / `trade.ohlc` / `trade.path` / `trade.lots` architecture.

- Objective
  - Keep the twelve clean-room Pine-derived profiles runnable and behaviorally honest on JavaScript.
  - Restore generic WGSL eligibility for the two native strategy examples and all twelve Pine-derived profiles.
  - Close every compiler, runtime, provider, transport, conformance, and documentation gap exposed by that catalog.
  - Extend beyond the selected historical profiles only where an explicitly documented Pine strategy capability is still missing.

- Non-negotiable boundaries
  - Keep one frontend and one canonical `Program`; do not add a strategy IR or strategy-only compiler.
  - Keep WGSL codegen bind-independent and the GPU runtime responsible for providers, bindings, devices, buffers, dispatch, and readback.
  - Keep broker, portfolio, and trade behavior in ordinary Tea libraries; codegen and runtime must not recognize their names.
  - Keep policy-specific direct trade coordinators; do not introduce a universal runtime Strategy value or broad wrapper.
  - Implement GPU struct semantics as nullable `StorageRef` values; never revive the obsolete inline-copy struct representation.
  - Reuse the versioned GPU artifact contract and the ordinary generated JavaScript bind sidecar; do not add a second bound-expression evaluator.
  - Fail closed on every unsupported or unbounded capability; never silently fall back to CPU or truncate effects.
  - Preserve source evaluation order, transactional mutation, history, aliasing, and provisional/commit semantics.
  - Keep all tests and fixtures repository-local and all clean-room references independently derived.

- Audited baseline
  - Frontend and CPU execution
    - All fourteen strategy sources pass load, check, and noding.
    - The twelve Pine-derived profiles use the canonical broker, portfolio, and trade libraries.
    - All published strategy sweep configurations currently select JavaScript.
    - CPU reference structs, collections, requests, transactional Heap storage, and report/effect publication are implemented.
  - GPU execution
    - Zero of fourteen strategy sources currently compile to WGSL.
    - Thirteen first fail at `struct-reference-lowering-unimplemented`.
    - Alice Grid first fails earlier because its effectful `while` loop has no provable transport bound; it also contains reference structs.
    - The real Dawn gate passes for the admitted scalar subset, including numeric ranges, temporal frames, bind-sized history, multi-binding execution, chunk resume, cache placement, dense output, and bounded primitive effects.
  - Historical capabilities already implemented
    - Numeric `for` ranges with runtime bounds, ascending/descending execution, `break`, and `continue`.
    - Bind-resolved and capped history allocation through the shared JavaScript bind sidecar.
    - `na`, float conversion, `math.abs`, `math.floor`, `math.max`, and `math.min` lowering.
    - Interned literal strings, string/color comparison, and primitive/enum/literal-string effect transport.
    - Resumable per-execution state, bounded chunking, workgroup-cache selection, and validated readback.
    - Direct trade-family composition and removal of strategy-local account engines.
  - Historical items no longer required by the current sources
    - ATR ZigZag and Cluster no longer construct dynamically concatenated command identifiers.
    - BB SPY no longer depends on arrays for its selected profile.
    - Dynamic GPU strings remain a generic target gap, but they are not a prerequisite for the current catalog when all reachable command identifiers have a finite interned domain.

- Implementation hierarchy
  - Establish an exhaustive capability ledger
    - Replace first-error-only catalog reporting with focused probes for every latent blocker.
    - Keep compilation fail closed while allowing audits to collect independent capability diagnostics.
    - Pin one minimal source fixture per missing generic WGSL capability.
    - Generate the strategy eligibility matrix from real compilation instead of hand-maintained README claims.
    - Re-establish deterministic closure-size, frame-size, shader-size, and maximum-effect ceilings for every strategy as it becomes eligible.

  - Implement GPU reference-struct storage
    - Extend the neutral GPU artifact ABI
      - Publish struct layout identities and field layouts.
      - Publish nullable reference encoding and per-execution Heap/storage requirements.
      - Publish allocation, mutation-journal, and effect-snapshot capacities without embedding concrete binding data in codegen.
      - Add any required producer-owned buffer bindings and descriptor offsets in `src/gpu/contract.ts` only.
    - Implement reference values
      - Represent every non-`na` struct as a `StorageRef`-compatible handle.
      - Preserve aliasing through assignment, arguments, returns, fields, tuples, collections, and history.
      - Preserve rebinding as a Name update without copying or replacing the referenced body.
      - Support null field reads and fail-before-arguments semantics for null writes and mutable calls.
      - Keep recursive and mutually recursive struct types finite through references.
    - Implement struct operations
      - Lower construction and bounded allocation.
      - Lower field reads and field stores.
      - Lower const and mutable method receivers without receiver copy-in/copy-out.
      - Store references in frame scratch, persistent state, and history rings.
      - Keep reference bodies live across chunks while any state root retains them.
    - Implement row transactions
      - Make allocations and in-place field mutations provisional until row commit.
      - Restore pre-row state on target errors and terminal capacity failures.
      - Keep effect publication after successful internal commit.
      - Define deterministic overflow behavior before any externally visible partial result.
    - Implement struct effects
      - Snapshot an emitted struct payload into an immutable bounded transport record at the emission point.
      - Recursively encode fixed acyclic payload fields, including finite interned strings and enums.
      - Detect recursive or otherwise unbounded payload graphs and fail eligibility explicitly.
      - Decode and validate the published schema without reconstructing layouts in the runtime.
    - Remove obsolete inline-struct lowering remnants
      - Replace dormant inline state/layout helpers rather than accidentally re-enabling value-copy semantics.
      - Add negative tests proving aliasing is not flattened into inline copies.

  - Restore the scalar strategy floor
    - Re-enable `ema-cross`.
    - Re-enable `cpu-gpu-next-open` and restore it as a real CPU/GPU example.
    - Re-enable Turtle System.
    - Re-enable ATR ZigZag Breakout.
    - Prove ordered lifecycle-effect parity, not only final metric parity.
    - Remove redundant copy-then-assign-back scaffolding in trade coordinators only after reference-mutation parity is locked.

  - Complete the required scalar and aggregate WGSL value surface
    - Exact time and wide-integer values
      - Choose and document an exact epoch-millisecond physical representation.
      - Pack `input.time` values without truncating them into the current i32 carrier.
      - Lower `time`, `time_close`, and the required historical reads.
      - Lower comparisons, division/modulo, day/session bucketing, and conversions used by the catalog.
      - Update the artifact numeric profile and ABI rather than disguising wide values as ordinary i32.
    - Required native operations
      - Add `math.sqrt` with Tea `na` and non-finite normalization.
      - Add `nz` with the same qualifier and typed-empty behavior as CPU.
      - Add `int` conversion with explicit truncation and range behavior.
      - Add integer modulo and any other native reached by the complete strategy closures.
      - Maintain a generated or test-enforced ledger from reachable native calls to WGSL rules.
    - Tuples
      - Publish deterministic fixed tuple layouts.
      - Lower tuple construction, projection, function returns, and destructuring.
      - Preserve element evaluation order and nullable element layouts.
      - Permit tuple request results when request execution lands.
    - Bind-only outputs
      - Carry output bind arguments through the artifact schema.
      - Preserve bind-argument evaluation order.
      - Define one CPU/GPU rule for bind-known plot values instead of rejecting them.
    - Remaining builtins required by admitted programs
      - Add `last_bar_index` and required `barstate.*` fields where the strategy closure reaches them.
      - Keep provider metadata builtins separate from numeric series and add only their declared typed layouts.

  - Implement bounded GPU collections and collection control flow
    - Shared storage model
      - Reuse the same bounded per-execution storage framework as reference structs.
      - Publish collection header, element layout, logical length, capacity, and backing-storage descriptors.
      - Preserve Tea collection-header value semantics and replacement-header mutation.
      - Support collection elements containing struct references.
    - Bind-sized capacity
      - Derive capacities from parameter constraints and bind-resolvable expressions.
      - Reject allocations whose maximum cannot be proven before dispatch.
      - Budget backing storage per binding and enforce device and caller memory limits.
    - Required array surface
      - Lower `array.new`, `array.size`, `array.get`, `array.set`, `array.push`, and `array.pop`.
      - Preserve bounds errors, typed-empty values, mutation ordering, and transactional replacement.
      - Support primitive arrays and arrays of struct references.
    - Collection iteration
      - Lower `for-in` over logical length rather than physical capacity.
      - Lower `while` only with a proven ranking function and maximum iteration count.
      - Recognize Alice Grid's decreasing-index loops without adding an arbitrary global trip-count limit.
    - Effect-capacity proofs
      - Extend effect analysis from compile-time numeric bounds to conservative bind-resolvable bounds.
      - Include transitive calls, collection iteration, and per-lot close/reversal paths.
      - Publish either a safe global maximum or validated per-binding capacity expression.
      - Keep runtime overflow detection as a defensive terminal failure, never as normal truncation.
    - Later collection families
      - Add matrix and map lowering only after array-backed catalog cases are complete.
      - Keep each later family behind the same explicit bounded-storage contract.

  - Implement GPU request-child execution
    - Artifact graph
      - Recursively compile every request child from the canonical child `Program`.
      - Publish child artifacts, dependencies, required inputs, frame/state layouts, result layouts, and merge policies.
      - Preserve compilation-global parameter sharing without flattening contexts into one Program.
    - Host-resolved context identities
      - Treat bind-static symbol and timeframe strings as provider identities, not shader strings.
      - Pack finite string/color/source parameters only when executable Tea code must read them on-device.
      - Run the existing bind sidecar to evaluate request contexts and options once in source order.
    - Child runtime
      - Resolve provider contexts and trailing-range demands through the existing `DataProvider` seam.
      - Execute child artifacts with isolated state and deterministic `timeNow`.
      - Preserve request-context budgets, errors, ignored-invalid behavior, and source/timeframe normalization.
    - Merge and parent reads
      - Implement gaps, lookahead, `calc_bars_count`, and parent-axis alignment exactly.
      - Publish or materialize parent-indexed merged result storage without runtime access to `Program`.
      - Lower parent request reads and request-result history.
      - Support tuple and aggregate child results only after their physical layouts are available.
    - Delivery order
      - Implement the static request pairs used by Alpha Regime, MTF PSAR, and Pair Spread first.
      - Add bounded dynamic-pair caching and between-dispatch suspension only as a separate later capability.
      - Keep network/provider resolution outside shader dispatch.

  - Complete string and effect transport
    - Preserve compile-time literal interning and deterministic literal IDs.
    - Propagate finite string IDs through struct fields, history, parameters, comparisons, and effect snapshots.
    - Add finite-domain analysis for branch-selected and call-returned strings used by the catalog.
    - Add concatenation only when the result domain is statically finite, or introduce a separately bounded string arena.
    - Keep truly unbounded strings fail closed.
    - Make effect schemas and decoding support every fixed payload shape used by broker lifecycle events.
