# Tea VS Code extension

Activation-free editor support for Tea `.tea` files in VS Code and compatible
editors such as Cursor.

## Invariants

- `src/syntax/tokens.ts`, `src/syntax/scanner.ts`, and `src/syntax/parser.ts`
  remain the syntax source of truth. Checker/catalog data may add semantic
  scopes, but never new syntax.
- `syntaxes/tea.tmLanguage.json` is generated by
  `scripts/generate-syntax.ts`; edit the generator and regenerate instead of
  editing the grammar directly.
- Contextual keywords are highlighted only in their governing declaration,
  import, or loop shapes. They remain ordinary identifiers elsewhere.
- This extension targets the clean-room `tea-lang` grammar. Do not merge in
  legacy TSGraph/Monaco keywords, operators, braces, or semicolons.
- The extension stays declarative: syntax highlighting must not require an
  activation entry point or runtime dependency.
